Topic 1Introduction to Deep Learning

In plain English

Deep learning is machine learning with big neural networks that find the useful features in raw data by themselves.

Remember
  • DL is a subset of ML, which is a subset of AI
  • DL does automated feature extraction; classical ML needs manual feature extraction
  • 3 driving forces: computing power, algorithm power, data availability
  • Pros: feature learning, complex problems, improves with more data
  • Cons: weak on small data, hard to interpret, high computation cost
Think of it as
Classical ML is a chef following your recipe (you pick the features). Deep learning is a chef who tastes thousands of dishes and works out the recipe alone. It needs lots of food (data) and a big kitchen (GPU).
In the test
  • Place DL inside AI and ML
  • Name the 3 driving forces
  • List advantages, disadvantages and frameworks

What deep learning is

  • Nesting: AI ⊃ Machine Learning ⊃ Deep Learning ⊃ Gen AI.
  • Inspired by the human brain, but does not work exactly like it. Usually means a deep/large Artificial Neural Network (ANN), made possible by big data.
  • Needs less human intervention than classical ML.
  • Key difference: in ML, a human does feature extraction before the ML algorithm. In DL, the neural network does automated feature extraction: Input → Neural Network → Output.
  • Strongest in computer vision (images/video), NLP (text), and speech recognition (audio).

History

  • 2010s: Andrew Ng (Stanford) with Google on the Google Brain project.
  • Ng's point: a large neural network keeps improving as more data becomes available, unlike other ML algorithms that plateau. With millions of samples, DL beats classical ML.
  • Three driving forces of DL growth: computing power, algorithm power, data availability.

Applications

Computer vision (face recognition, autonomous driving, image restoration, motion/3D pose), healthcare (TB detection, robotic surgery, brain-bleed and Alzheimer's detection), NLP and speech (Echo Dot, chatbots, audiobook narration, music composition), entertainment and gaming, education (adaptive learning, individualised instruction), generative AI (ChatGPT, Midjourney, Sora).

DL algorithms (names to recognise)

ANN, MLP, RBFN, CNN, RNN, LSTM, GAN, RBM, SOM, DBN, Autoencoders, Transformer, Stable Diffusion.

Advantages
Feature learning: discovers features from raw data automatically, less reliance on domain experts
Complex problems: images, video, NLP, speech
Large data: keeps improving as data grows
Disadvantages
Small data: may lose to decision tree or k-NN
Interpretation: hard to explain (a decision tree is easy to explain)
Computation cost: huge number of parameters; eased by GPUs/TPUs/CUDA

Frameworks

Future trends

Continued AI advances · more automation (manufacturing, healthcare, transport, finance) · human–AI collaboration · explainability and transparency (critical in healthcare/finance) · quantum computing · AI-dedicated hardware.

Topic 2.1Fundamentals of Neural Networks

In plain English

A neuron multiplies each input by a weight, adds them up with a bias, and passes the total through an activation function. Stack many of these in layers and you have a neural network.

Remember
  • Neuron: y = f(Σ wᵢxᵢ + b)
  • Input layer does no computation; hidden layers transform; output layer gives the result
  • Deep = 2 or more hidden layers
  • Capacity = depth, width, connectivity, number of parameters
  • Forward propagation predicts; backward propagation trains
Think of it as
A neuron is a voter: each input is an opinion, the weight is how much it trusts that opinion, and the bias is its own leaning. The activation decides whether it speaks up.
In the test
  • Compute one neuron's output
  • Name the layers and say what each does
  • Count parameters: inputs × neurons + neurons

Biological vs artificial neuron

BiologicalArtificial
Dendrites receive signalsInputs xi (input channels)
Cell body processesWeighted sum + activation (processing stage)
Axon sends output (via synapses)Output y, fans out to next neurons
Neuron model
y = f( Σi=1..n wixi + b )

x = inputs, w = weights, b = bias (a constant added to the weighted sum), f = activation function.

Worked example · one neuron
x = [2, −1, 3], w = [0.5, 0.4, 0.2], b = 0.1 z = 2(0.5) + (−1)(0.4) + 3(0.2) + 0.1 = 1 − 0.4 + 0.6 + 0.1 = 1.3 Sigmoid: y = 1/(1+e^−1.3) = 0.786 ReLU: y = max(0, 1.3) = 1.3

Architecture

  • Input layer: feeds data in. No computation in input neurons.
  • Hidden layers: no direct connection to outside; transform data into higher-dimensional space; output goes to the next layer.
  • Output layer: computes and sends results out. Regression → usually 1 neuron. Classification → one neuron per class (binary uses 1 sigmoid neuron).
  • Deep neural network = 2 or more hidden layers. "Deep" refers to many hidden layers.
  • Each layer holds state parameters: weights and bias. These form the knowledge the network has learned.

Capacity

  • Depth = number of hidden layers · Width = neurons per layer · Connectivity = how neurons connect · Parameters = total count.
  • More neurons and weights = higher capacity = can learn more complex problems.
  • Wrong capacity → underfitting (too small) or overfitting (too large). There is no analytical rule for the best depth/width.

How it works

  • Forward propagation → makes a prediction (input → output, no feedback).
  • Backward propagation → optimises/trains the weights (output → input).
Parameters in a Dense layer
params = (inputs × neurons) + neurons

One weight per connection, one bias per neuron. Practical 2 MNIST net 784 → 20 → 10: (784×20+20) + (20×10+10) = 15,700 + 210 = 15,910.

Topic 2.2Build a Neural Network using Python

In plain English

Building a network from scratch is a loop: predict (forward), measure the error (loss), work out which way to nudge each weight (backward), nudge them (gradient descent), and repeat.

Remember
  • 7 steps: prepare data → define & compile → train → evaluate → optimize → predict → save/deploy
  • Single-layer NN: input and output layer only
  • W shape = (neurons in this layer) × (neurons in previous layer)
  • Gradients have the same shape as the weights they update
Think of it as
Learning to throw darts: throw, see how far off you were, adjust your arm a little in the right direction, throw again.
In the test
  • List the 7 general steps
  • Do one single-layer update w + η(t − p)x
  • Give the shapes of W1, b1, W2, b2

General steps of building an ANN (7 steps)

2. Define and compileDefine layers and neurons, activation functions, loss function, optimizer
3. TrainLearn (determine) the weights and bias from the training dataset
4. EvaluateChoose evaluation methods; compare and verify results

Single-layer neural network

  • The simplest NN: only an input layer and an output layer (no hidden layer).
  • 3 components: input neurons, the sum of the weighted inputs (like the cell membrane), and the output from the activation function (sigmoid in the practical).
  • Practical 1 build order: prepare data → weighted sum → activation function → loss function → optimizer (gradient descent) → initialise and train (plot the loss curve) → predict.
def get_weighted_sum(x, w, b):  return x @ w + b          # np.dot(x, w) + b
def sigmoid(z):                 return 1 / (1 + np.exp(-z))
def cross_entropy(t, p):        return -(t*np.log10(p) + (1-t)*np.log10(1-p))
def update_weights(x, w, lr, t, p): return [wi + lr*(t - p)*xi for xi, wi in zip(x, w)]
def update_bias(b, lr, t, p):   return b + lr*(t - p)
# initial: weights = [0.5, 0.5], bias = 0.5, l_rate = 0.01, epochs = 500
# predict: class 1 if sigmoid(sum) > 0.5, else class 0
Worked example · one training step of the single-layer NN
x = [0.4, 0.8], w = [0.5, 0.5], b = 0.5, target t = 1, η = 0.1 Weighted sum: z = 0.4(0.5) + 0.8(0.5) + 0.5 = 1.1 Prediction: p = sigmoid(1.1) = 0.7503 → class 1 (p > 0.5) Loss: −log₁₀(0.7503) = 0.125 Error: t − p = 0.2497 Update: w₁ = 0.5 + 0.1(0.2497)(0.4) = 0.5100 w₂ = 0.5 + 0.1(0.2497)(0.8) = 0.5200 b = 0.5 + 0.1(0.2497) = 0.5250
Sign of the update

The practical writes w + η(t − p)x. That is the same as w − η(p − t)x: gradient descent moves against the gradient, and the gradient here is (p − t)x. If the prediction is too low (p < t), the weights go up.

  • Input: 784 units · Hidden: 20 units, ReLU · Output: 10 units, softmax (digits 0–9). Trained on 3000 examples.
  • Z = weighted sum of a neuron; A = output of the neuron after its activation function.

Topic 2.3Activation Functions

In plain English

An activation function bends the neuron's output so the network can learn curves, not just straight lines. Pick ReLU for hidden layers and choose the output one by task.

Remember
  • Activation functions add non-linearity
  • Sigmoid (0 to 1), f′ = f(1 − f); tanh (−1 to 1), f′ = 1 − f²
  • ReLU = max(0, x): the default for hidden layers
  • Sigmoid/tanh → vanishing gradient; ReLU → dying ReLU (fix: Leaky ReLU)
  • Output: regression → linear, binary → sigmoid, multi-class → softmax
Think of it as
A dimmer switch on each neuron. Without it, stacking layers is like stacking straight rulers: you still only get a straight line.
In the test
  • Write each function, its range and its derivative
  • Explain vanishing gradient and dying ReLU
  • Pick the output activation for regression, binary and multi-class

Purposes

  1. Firing decision: like a switch, decides if a neuron fires (only relevant neurons fire).
  2. Bounded values: some limit output, e.g. [0,1], which gives stability.
  3. Non-linearity: real problems are non-linear; without a non-linear activation, stacked layers collapse into one linear function.

Desirable properties

Differentiable (for gradient-based optimisation) · bounded output (saturates at both ends) · sensitive to changes in the middle · non-linear · able to switch neurons on/off. Sigmoid satisfies most of these.

Exam traps
  • Vanishing gradient: sigmoid and tanh saturate at both ends, so gradients ≈ 0 and learning gets stuck. Severe in RNNs.
  • Dying ReLU: a neuron stuck in the negative region always outputs 0, gets zero gradient, and stops learning. Fix: Leaky ReLU.
  • ReLU looks linear but is non-linear (output is 0 for x<0).
  • There is no activation function on the input layer.

Topic 2.4Loss Functions

In plain English

The loss is a single number saying how wrong the predictions are. Training means making it smaller. Use MSE for numbers and cross-entropy for classes.

Remember
  • The loss measures the error between predicted and true values; training minimises it
  • Regression → MSE; binary → binary cross-entropy; multi-class → categorical cross-entropy
  • Cross-entropy heavily penalises confident wrong predictions
  • MSE with sigmoid gives a non-convex loss (local minima)
Think of it as
A golf score: lower is better. Cross-entropy is a strict referee who gives a huge penalty for being confidently wrong.
In the test
  • Compute MSE
  • Compute binary cross-entropy with log₁₀ like the slides
  • Explain why MSE is a bad choice for classification
  • Loss = error between predicted and true output: high for bad predictions, low for good.
  • Training aims to minimise the loss by iteratively adjusting weights. This is called optimisation, usually via gradient descent.
  • An ideal loss is convex (one global minimum).
Mean squared error (regression, linear output)
MSE = (1/n) Σ (yᵢ − ŷᵢ)²

yᵢ = ground truth, ŷᵢ = prediction, n = number of samples.

Worked example · MSE
y = [3, 5, 2], ŷ = [2.5, 5.5, 3] MSE = [(0.5)² + (−0.5)² + (−1)²]/3 = (0.25 + 0.25 + 1)/3 = 0.5
Binary cross-entropy (sigmoid output)
loss = −(1/n) Σ [ yᵢ log(ŷᵢ) + (1 − yᵢ) log(1 − ŷᵢ) ]

If y = 1 only the first term counts: −log(ŷ). If y = 0 only the second: −log(1 − ŷ). Probability form: p = ŷy(1−ŷ)1−y. Also called log loss.

Worked example · BCE (slide, log₁₀)
Labels y = [1, 0, 1, 0], predictions ŷ = [0.9, 0.55, 0.51, 0.9] S1 y=1: log(0.9) = −0.046 correct + sure → small loss S2 y=0: log(1−0.55) = −0.347 wrong → large loss S3 y=1: log(0.51) = −0.292 correct + unsure → large loss S4 y=0: log(1−0.9) = −1.000 very wrong + sure → heavily penalised Loss = −¼ (−0.046 − 0.347 − 0.292 − 1.000) = 0.421
Worked example · compare two classifiers (slide activity)
Classifier 1: −⅓[log(1−0.8) + log(0.1) + log(1−0.1)] = −⅓[−0.699 − 1 − 0.046] = 0.582 Classifier 2: −⅓[log(1−0.1) + log(0.8) + log(1−0.1)] = −⅓[−0.046 − 0.097 − 0.046] = 0.063 Lower loss wins → Classifier 2 is better.
Multi-class (categorical) cross-entropy (softmax output)
loss = −(1/n) Σᵢ Σc=1..m [ yi,c log ŷi,c + (1 − yi,c) log(1 − ŷi,c) ]

m = number of classes, n = number of samples. This is the form used in the slides.

Worked example · 4-class (dog, cat, horse, cheetah)
True y = [1, 0, 0, 0] (dog), softmax ŷ = [0.775, 0.116, 0.039, 0.070] Loss = −[log(0.775) + log(1−0.116) + log(1−0.039) + log(1−0.070)] = −[−0.111 − 0.054 − 0.017 − 0.032] ≈ 0.21 (slide shows 0.215)
Which formula?

The slides apply the full y·log ŷ + (1−y)·log(1−ŷ) form to every class. Keras's standard categorical cross-entropy only keeps the true class: −log(ŷtrue) = −log₁₀(0.775) = 0.111. In the exam, use the slide formula unless the question gives you a different one, and show each term.

Why not MSE for classification?

  • MSE measures a difference between values. Cross-entropy measures dissimilarity between two probability distributions (predicted vs true).
  • MSE with sigmoid outputs gives a non-convex cost with many local minima, so gradient descent may get stuck in a local minimum instead of the global one.
  • Cross-entropy, because of the log curve, heavily penalises confident wrong predictions, which gives faster convergence for classification.

Topic 2.5Backpropagation & Optimizers

In plain English

Backpropagation uses the chain rule to find how much each weight caused the error. The optimizer then moves each weight a small step (the learning rate) downhill.

Remember
  • Backpropagation = chain rule + gradient descent, from output back to input
  • Update: w = w − η × ∂E/∂w (move opposite the gradient)
  • Learning rate too big → overshoots; too small → slow
  • Momentum escapes local minima; Adagrad gives per-weight rates; RMSprop uses a moving average; Adam combines them (default)
  • Stochastic = 1 sample, batch = all samples, mini-batch = small groups
Think of it as
Walking down a foggy hill: feel the slope under your feet (gradient), take a step downhill (learning rate). Momentum is a rolling ball that can roll over small dips.
In the test
  • Do one backprop update with the chain rule
  • Compute learning-rate decay and momentum
  • Compare SGD, Adagrad, RMSprop and Adam, and stochastic vs batch vs mini-batch

Backpropagation

  • Also called reverse-mode differentiation; invented in the 1970s.
  • Uses gradient descent + the chain rule to work out how to adjust each weight.
  • Starts at the output layer (where the error is computed) and works back toward the input.
  • The training loop: Input → layers → prediction ŷ → loss function → optimizer → update weights.
  • DL needs 3 components: NN model, loss function, optimizer.
Chain rule
dy/dx = dy/du × du/dx

Example: y = √(2x+1). Let u = 2x+1, so y = u1/2. dy/dx = ½u−1/2 × 2 = (2x+1)−1/2.

Network from the slides (sigmoid neurons, E = ½(a − y)²)
h₂ = w₁₂a₁ + w₂₂a₂, a = σ(h₂)
∂E/∂w₁₂ = ∂E/∂a × ∂a/∂h₂ × ∂h₂/∂w₁₂ = (a − y) · a(1 − a) · a₁
∂E/∂w₁₁ = x₁ · a₁(1 − a₁) · w₁₂ · a(1 − a) · (a − y)
wnew = w − η × ∂E/∂w

The three pieces: ∂E/∂a = (a − y) from the ½ in the loss; ∂a/∂h = a(1−a) from the sigmoid derivative; ∂h/∂w = the input arriving on that weight.

Worked example · one backprop update
Given a₁ = 0.6, a₂ = 0.4, w₁₂ = 0.5, w₂₂ = −0.3, target y = 1, η = 0.1 Forward: h₂ = 0.5(0.6) + (−0.3)(0.4) = 0.30 − 0.12 = 0.18 a = σ(0.18) = 1/(1+e^−0.18) = 0.5449 Backward: ∂E/∂a = a − y = −0.4551 ∂a/∂h₂ = a(1−a) = 0.2480 ∂h₂/∂w₁₂ = a₁ = 0.6 ∂E/∂w₁₂ = −0.4551 × 0.2480 × 0.6 = −0.0677 Update: w₁₂ = 0.5 − 0.1 × (−0.0677) = 0.5068 (weight increases → output moves toward 1)

Gradient descent

  • Optimisation = finding the x that minimises f(x). The optimizer decides how to adjust weights, by how much, in which direction, and when to stop.
  • Update: w = w − η·J′(w), b = b − η·J′(b). Move opposite to the gradient.
  • The gradient has the same shape as the weights.
  • Stops when the derivative ≈ 0: a stationary / critical point.
  • For f(x) = x², f′(x) = 2x. If x < 0, f′ is negative → move right. If x > 0, f′ is positive → move left.
Worked example · gradient descent on f(x) = x²
x₀ = 3, η = 0.1, f′(x) = 2x x₁ = 3 − 0.1(6) = 2.4 x₂ = 2.4 − 0.1(4.8) = 1.92 → shrinking toward the minimum at x = 0
  • Convex function: unique global minimum; a line joining any two points lies on or above the curve. GD finds the global minimum only if the loss is convex.
  • Most DL losses are not convex, so DL does not guarantee the best possible solution (it may stop at a local minimum).

SGD training steps

  1. Set a learning rate η
  2. Initialise the weights
  3. Randomly select examples
  4. Get a prediction ŷ
  5. Calculate the loss
  6. Calculate the gradient of the loss w.r.t. the weights
  7. Adjust weights in the opposite direction of the gradient
  8. Repeat for a fixed number of times or until weights stabilise

Learning rate and decay

  • Too large → overshoots / diverges. Too small → very slow. It controls the speed of convergence.
  • SGD's random sampling adds noise, so reduce the learning rate gradually, then hold it constant after T iterations: learning rate decay.
Linear learning-rate decay
rk = (1 − k/T)·r₀ + (k/T)·rT (for k ≤ T; rk = rT after)
Worked example · r₀ = 0.4, rT = 0.1, T = 5
r₁ = 0.8(0.4) + 0.2(0.1) = 0.34 r₂ = 0.6(0.4) + 0.4(0.1) = 0.28 r₃ = 0.4(0.4) + 0.6(0.1) = 0.22 r₄ = 0.2(0.4) + 0.8(0.1) = 0.16 r₅ = 0.0(0.4) + 1.0(0.1) = 0.10 → constant from here

Optimizers

OptimizerKey idea
SGDBasic gradient descent on randomly chosen samples; one fixed learning rate
MomentumAdds back part of the previous weight change: Δwt = −η J′(w) + m·Δwt−1. Helps escape local minima and speeds up learning; m is the momentum parameter

Stochastic vs batch vs mini-batch

  • Stochastic (online): 1 random sample per update.
  • Batch (deterministic): the whole training set per update, using the average gradient.
  • Mini-batch: small groups (16, 32, 64, 128…, chosen to fit memory). Smaller → converges quicker, less accurate gradients. Larger → converges slower, more accurate. Tune batch size last (it interacts little with other hyperparameters).
AdvantagesDisadvantages

Epoch = one full pass over all training data. Iteration/step = one weight update (one batch). Steps per epoch = ⌈samples / batch size⌉.

Topic 4.1Fundamentals of CNN

In plain English

A CNN looks at small patches of an image with filters, so it keeps the spatial layout that a normal network loses when it flattens the image.

Remember
  • ANNs flatten images and lose spatial relationships
  • Greyscale = H × W; colour = H × W × 3 (RGB), values 0–255
  • Image attributes: spatial correlation, translation invariance, hierarchy of features
  • CNN: conv → pool (repeat) → flatten → dense → output
  • Filter values are learned weights
Think of it as
Reading a page through a small magnifying glass you slide around. You spot edges first, then shapes, then whole objects.
In the test
  • Explain why ANNs struggle with images
  • Describe how images are stored (H × W × channels)
  • Name the 3 image attributes and the CNN layers in order

How humans recognise objects (CNN's inspiration)

Detect simple features first (edges, curves, corners, colour boundaries) → focus on connected colour blocks, ignore blank space → combine into parts (eyes, wheels) → group and count parts → match to known objects. Recognition is hierarchical.

Limitation of ANN for images

A fully connected ANN flattens the 2D image into a 1D vector, so it:

  • treats pixels as independent and ignores spatial relationships between neighbours
  • loses spatial information and hierarchical structure
  • weakens classification and lowers accuracy (and needs huge numbers of weights)

Main ideas of CNN

  • Some patterns are much smaller than the whole image → use small detectors with few parameters.
  • The same pattern appears in different places → slide the same detector around the image (parameter sharing).

Image representation

  • Greyscale: 2D matrix [height][width]; pixel values 0–255 (or 0–1 after normalising).
  • Colour: 3D matrix [height][width][channels]; usually RGB = 3 channels, each 0–255.
  • Coordinates: origin [0,0] is the top-left; index increases to the right and down; access as X[row, col].

Image data attributes

  • Spatial correlation: nearby pixels are highly correlated.
  • Translation invariance: a feature can be anywhere.
  • Hierarchy of features: big features are made of small ones.

Convolutional filters

  • Also called kernels / masks: small 2D matrices for blurring, sharpening, edge detection, embossing.
  • Traditionally hand-tuned; in a CNN the filter values are learned weights.
  • Early conv layers learn general features (edges); deeper layers learn abstract features (wheels, eyes, then whole objects).

CNN architecture

Input → [Convolution → Pooling] × n → Flatten → Dense → Output (softmax or sigmoid, one unit per class).

History

  • 1959Hubel & Wiesel: two cell types in the visual cortex, cascading model
  • 1980Fukushima: Neocognitron (recognition network, CNN-like)
  • 1982–85Hinton, LeCun et al.: CNN with sigmoid activation
  • 1990Yann LeCun: CNN for handwritten digit recognition
  • 2007Fei-Fei Li: ImageNet (15M+ images)
  • 2010ILSVRC competition starts
  • 2012AlexNet (Krizhevsky) wins: CNN + ReLU + data augmentation + dropout + GPU
  • 2014VGGNet (Visual Geometry Group, Oxford)
  • 2015ResNet (Kaiming He, Microsoft Research): residual blocks

ImageNet (ILSVRC): 1000 classes, 1,281,167 training, 50,000 validation, 100,000 test images. Computer vision tasks: image classification, segmentation and object detection.

Topic 4.2CNN Layers

In plain English

Convolution slides a filter over the image and records a score at each spot. Padding keeps the size; pooling shrinks it. The filters are the weights that get learned.

Remember
  • Convolution slides a filter and sums element-wise products to make a feature map
  • Output size = ⌊(N − F + 2P)/S⌋ + 1
  • Conv params = F × F × C_in × K + K
  • Padding 'same' keeps the size; 'valid' means no padding
  • Pooling has no parameters; max keeps the biggest value, average takes the mean
  • GAP turns h × w × d into 1 × 1 × d
Think of it as
A stencil moved across a picture, noting how well each patch matches. Pooling summarises each 2×2 block by its strongest signal.
In the test
  • Compute a convolution output by hand
  • Use ⌊(N − F + 2P)/S⌋ + 1 for output size
  • Count parameters: F × F × C × K + K
  • Do max and average pooling

Convolutional layer

  • Convolution = slide a filter across the image, multiply element-wise, and sum. Each filter is a feature detector and produces one feature map.
  • Filters are usually square with odd size (3×3, 5×5) so there's a centre pixel.
  • A conv layer has several filters; k filters → k feature maps.
  • Each feature map gets one bias; the default activation is ReLU: a = ReLU(Σxw + b).
  • Learnable parameters = filter weights and biases.

Colour (RGB) images

  • Filter depth must equal input channels: a 6×6×3 image needs a 3×3×3 filter. One 3D filter → one 2D feature map (6×6×3 ⊛ 3×3×3 → 4×4×1). Sum over all 3 channels.
  • 2 filters (3×3×3×2) → output 4×4×2.

Three key characteristics of conv layers

  1. Spatial local patterns as detectors: small local filters with few parameters. (Dense layers learn global patterns; conv layers learn local ones.)
  2. Translation invariance: a pattern learned in one corner is recognised anywhere.
  3. Spatial hierarchies: layer 1 learns edges, layer 2 learns bigger patterns built from them, and so on.

Padding

  • Without padding, the image shrinks every layer (6×6 → 4×4 → 2×2) and edge pixels are under-used.
  • Padding adds a border of zeros to preserve output size and reduce edge information loss.
  • Keras: padding='valid' = no padding (default) · padding='same' = output same size as input (stride 1).
  • 5×5 input with a 3×3 filter: valid → 3×3; same → 5×5 (pad 1).

Pooling layer

  • Purpose: down-sample feature maps and keep salient/dominant features. The object stays the same while the image gets smaller.
  • No learnable parameters.
  • Why: lets higher layers learn bigger, more abstract patterns; reduces the weights in the flattened dense layer (less overfitting); reduces computation; adds translation invariance.
  • Methods: max pooling (largest value in each patch), average pooling (mean), global average pooling.

Global average pooling (GAP)

  • Reduces each h×w feature map to one number (its average): (h×w×d) → (1×1×d).
  • Replaces the dense layers at the end of a CNN → far fewer parameters, faster training, less overfitting.
  • Two ways to use it: (1) no dense layer: the last conv layer must have as many filters as classes, then softmax; (2) with one dense layer: the filter count need not match the class count.

Structured · 6

1. List the 7 general steps of building an ANN.
Prepare data → define and compile → train → evaluate → optimize → make predictions → save/deploy.
2. List three desirable properties of activation functions.
Any three: differentiable, bounded output, sensitive to change in the middle range, non-linear, can switch neurons on/off.
3. Explain the vanishing gradient and dying ReLU problems, and name a fix for dying ReLU.
Vanishing gradient: sigmoid/tanh saturate at large |x|, so gradients ≈ 0 and the weights stop updating. Dying ReLU: a neuron whose input stays negative always outputs 0 and has zero gradient, so it never learns. Fix: Leaky ReLU (small slope α for x < 0).
4. Give two limitations of using a fully connected ANN for images, and how CNN solves them.
Flattening ignores spatial relationships between neighbouring pixels and loses hierarchical structure; it also needs a huge number of weights. CNNs use small local filters (local patterns, few parameters) shared across the image (translation invariance), stacked to learn spatial hierarchies.
5. Compare stochastic, batch and mini-batch training (one advantage and one disadvantage each).
Stochastic: frequent updates and low memory, but noisy and slow to converge. Batch: most accurate updates and parallelisable, but huge memory use and may get trapped in a local minimum. Mini-batch: balances both and fits memory, but adds the batch-size hyperparameter and needs padding for the last batch.
6. Why use pooling layers? Why can GAP replace the dense layers?
Pooling down-samples, keeps dominant features, cuts computation and the parameters of the following dense layer (less overfitting), and adds translation invariance. GAP averages each feature map to one value, so no large dense weight matrix is needed. That means far fewer parameters, faster training and less overfitting.
