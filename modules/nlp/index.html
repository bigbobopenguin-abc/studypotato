Topic 1Introduction to NLP

Natural Language Processing (NLP) is the part of AI that lets computers understand, interpret and generate human language.

  • 1950sNLP begins

  • 2017Transformers ("Attention is all you need", Vaswani et al.): the basis of today's language models
  • NowBERT, GPT, Gemini, Claude and other chatbots

The big picture pipeline

Raw text → clean and tokenise → understand grammar (POS, chunking, NER) → turn into numbers (one-hot, BoW, TDM/TTM, TF-IDF/PPMI, embeddings) → model (Naive Bayes, logistic regression, CNN, Transformer) → compare or classify.

Byte Pair Encoding (BPE)

The subword method used by Transformers.

  1. Split every word into single characters.
  2. Start the vocabulary with those characters.
  3. Find the most frequent adjacent pair.
  4. Merge it into a new token and add it to the vocabulary.
  5. Repeat 3–4 until the vocabulary reaches the target size.

Other cleaning steps

Stop-word removalRemoves common filler words with little meaningthe, and, is, a
StemmingCrudely chops endings; result may not be a real wordrunning → run, flies → fli, cities → citi
LemmatisationReturns the dictionary form (lemma); always a real wordflies → fly, cities → city, mice → mouse
Memory hook

Stemming is a rough haircut; lemmatisation is a proper barber. If the result isn't a dictionary word, it was stemming.

Topic 3Part-of-Speech Tagging and HMM

  • POS tagging labels every word with its grammatical role (noun, verb, adjective…).
  • It resolves ambiguity: "book" can be a noun or a verb; "Washington" can be a person or a place.
  • NLTK tags to know: DT determiner (the, a) · JJ adjective · NN noun · VB verb · MD modal (can, will).
  • Approaches: statistical (Hidden Markov Model: simple, no deep meaning) and neural (RNN, LSTM, Transformer: better context).

Hidden Markov Model (no equation given in the test)

Emission probability
P(word | tag) = count(word with tag) ÷ count(tag)

How likely a tag "emits" this word. Divide by the total for the tag (column total), not the word.

Transition probability
P(tag₂ | tag₁) = count(tag₁ → tag₂) ÷ count(all transitions out of tag₁)

Add <S> at the start and <E> at the end of every sentence before counting pairs.

Score of one tagging
P = Π P(tagᵢ | tagᵢ₋₁) × P(wordᵢ | tagᵢ) (including <S> → first and last → <E>)

Multiply every transition and emission along the path. Highest score wins. Any zero makes the whole path 0.

Text vectorisation = turning text into numbers. From simplest to most advanced: One-hot → Bag of Words → TDM/TTM → TF-IDF/PPMI → Word2Vec/GloVe/FastText.

One-hot encoding

Each word = a vector of 0s with a single 1 at its own index. Vocabulary [cat, dog, fish]: dog = [0, 1, 0].

Bag of Words

Each sentence = word counts; order ignored. "dog bites dog" over [bites, cat, dog] = [1, 0, 2].

3 problems with one-hot and BoW
  1. Sparse and high-dimensional: long vectors, mostly zeros, waste memory.
  2. No meaning: "cat" and "kitten" look unrelated (their dot product is 0).
  3. Can't handle OOV words.

Word embeddings: Word2Vec (skip-gram with negative sampling)

  • Embeddings are short, dense, learned vectors with almost no zeros.
  • Positive samples: real (target, neighbour) pairs from a window. "…a tablespoon of apricot jam, a pinch…" gives (apricot, tablespoon), (apricot, of), (apricot, jam), (apricot, a).
  • Negative samples: target paired with random words, e.g. (apricot, aardvark); several per positive pair.
  • Train a binary classifier to tell real from fake; the learned weights become the word vectors.
  • Every word has two vectors: one as target (W) and one as context (C). Start random; SGD pulls real neighbours together and pushes fake ones apart.
Skip-gram probability
P(+ | w, c) = σ(w·c) = 1 / (1 + e^(−w·c)) P(− | w, c) = 1 − σ(w·c) = 1 / (1 + e^(w·c))
Worked example
w = [1, 2], c = [0.5, 1] → w·c = 0.5 + 2 = 2.5 P(+) = 1/(1 + e^−2.5) = 0.924 P(−) = 1 − 0.924 = 0.076
  • Window size (1–10 each side): small window → syntactic similarity (same part of speech); large window → topical similarity.
  • Analogies: king − man + woman ≈ queen, Paris − France + Italy ≈ Rome.
  • Evaluation: extrinsic (performance on real NLP tasks) and intrinsic (compare with human similarity ratings, e.g. WordSim-353: 353 pairs rated 0–10; (plane, car) = 5.77).
  • GloVe: vectors from global co-occurrence statistics, no labelled data. FastText: Facebook AI library for embeddings and text classification (uses subwords, so it handles OOV words).

v·w = Σ vᵢwᵢ |v| = √(Σ vᵢ²) cos θ = (v·w) / (|v| |w|)

Topic 7TF-IDF and PPMI

Raw counts overrate frequent but uninformative words ("the", "good"). Both methods re-weight counts.

Used withAsks
TF-IDFTDM (words × documents)Is this word frequent here but rare elsewhere?
PPMITTM (words × words)Do these two words co-occur more than chance?

TF-IDF

Formulas (log base 10)
TF = log₁₀(count + 1)
IDF = log₁₀(N / df) N = total documents, df = documents containing the word
TF-IDF = TF × IDF

A word in every document has IDF = log₁₀(1) = 0, so it gets weight 0. "Romeo" (1 play) has a high IDF; "sweet" (most plays) a low one.

Worked example · "battle" in As You Like It
count = 1, appears in 21 of 37 plays TF = log₁₀(1 + 1) = 0.301 IDF = log₁₀(37/21) = log₁₀(1.762) = 0.246 TF-IDF = 0.301 × 0.246 = 0.074

PPMI

Formula (log base 2)
PMI(w, c) = log₂ [ P(w, c) / (P(w) P(c)) ] PPMI = max(PMI, 0)
P(w, c) = f(w,c) / N P(w) = row total / N P(c) = column total / N

Numerator = how often they actually co-occur; denominator = how often by chance if independent. Negative values become 0 (the "positive" in PPMI), because negative PMI is unreliable on small counts.

Worked example · PPMI(information, data)
P(information, data) = 3982 / 11716 = 0.3399 P(information) = 0.6575 P(data) = 0.4842 PPMI = log₂(0.3399 / (0.6575 × 0.4842)) = log₂(0.3399 / 0.3184) = log₂(1.0677) = 0.0944
Centroid (document vector)
d = (w₁ + w₂ + … + wₖ) / k

Average of the document's word vectors. Example: [1, 3] and [3, 5] → [2, 4].

Text classification

  • Text classification groups text into categories (spam vs non-spam). Models learn from labelled examples.
  • Binary: two categories (spam / not spam). Multi-class: more than two (negative / neutral / positive).
  1. Prepare a labelled dataset
  2. Split into training and test sets
  3. Convert text into numerical feature vectors
  4. Train the model on training data and labels
  5. Evaluate with a suitable metric

Naive Bayes (no equation given in the test)

  • Uses Bayes' theorem to calculate the probability of each class and picks the most likely one.
  • Treats a document as a bag of words: order ignored, only frequency counts.
  • Naive assumption: each word is independent of the others, so a sentence's probability is the product of its word probabilities. Without it, any sentence not seen exactly in training gets probability 0.
Bayes' theorem for a class
P(class | text) = P(text | class) × P(class) / P(text)
P(text | class) = P(w₁ | class) × P(w₂ | class) × …

P(text) is the same for both classes, so ignore the denominator and compare P(class) × Π P(wᵢ | class).

Prior and Laplace (add-1) smoothing
P(class) = documents in class ÷ total documents
P(word | class) = (count of word in class + 1) ÷ (total words in class + vocabulary size)

A word that never appears in a class would give 0 and wipe out the product. Add 1 to every count, and add the vocabulary size to the denominator so the probabilities still sum to 1.

  • The vocabulary is 19 because it includes "i". Count every unique word across both classes.
  • Don't forget to multiply by the prior at the end.
  • The final numbers are scores to compare, not true probabilities (they don't sum to 1, since P(text) was dropped).

Topic 9Binary Logistic Regression

  • Predicts a binary output (0 or 1) from a feature vector x = [x₁, …, xₖ].
  • Features can be word counts, word embeddings or N-grams.
  • N-grams = sequences of N consecutive items. Unigrams: "The", "quick", "brown", "fox". Bigrams: "The quick", "quick brown", "brown fox".
  • The model learns weights and a bias b. Each weight is a feature's influence: positive words like "awesome" get large positive weights, negative words like "abysmal" large negative ones.
The model
z = Σ wᵢxᵢ + b = w·x + b
σ(z) = 1 / (1 + e^−z) = 1 / (1 + e^−(w·x + b)) = P(y = 1 | x)
decision(x) = 1 if P(y = 1 | x) > 0.5, otherwise 0

The decision threshold is 0.5, which is the same as z > 0. σ(0) = 0.5.

Topic 10Convolutional Neural Network

  • A deep network designed for visual data (image classification, face recognition, object detection), also used for NLP: text classification, sentiment analysis.
  • Two parts: feature extraction (convolution, activation, pooling, repeated) and classification (fully connected network).
  • Convolution: a filter (kernel) slides across the input, taking a dot product at each position. The results form a feature map (activation map).
  • Filter size sets the neuron's receptive field; stride sets how far the filter moves. Both are hyperparameters.
  • For text: the input is a sentence matrix (one row per word embedding, e.g. 7 words × d = 5). Filters span the full embedding width and cover 2, 3 or 4 words (region sizes); 1-max pooling takes the largest value per feature map; the results are concatenated and fed to softmax.

Dropout and the classifier

  • Overfitting: good on training data, poor on unseen data.
  • Dropout randomly disables neurons during training so the model generalises better.
  • The feature maps are flattened into a 1D vector and fed to a fully connected network. The number of hidden layers is a hyperparameter.

Topic 11Transformer Architecture

  • Original Transformer ("Attention is all you need", Vaswani et al., 2017): encoder–decoder, built for translation.
  • Encoder: turns input tokens into contextual embedding vectors. Decoder: uses the encoder's output to generate output tokens one at a time.
  • Processes the sequence in parallel (not word by word like an RNN), so it trains efficiently on GPUs/TPUs.
TypeDoesTasksExamples
Encoder-onlyText → numerical representationText classification, NERBERT, RoBERTa, DistilBERT
Decoder-onlyPredicts the next token step by stepText generation ("The solar system has …")GPT
Encoder–decoderSequence → sequenceTranslation, summarisationBART, T5

Self-attention

  • Helps the model understand a word through its context. In "book a plane ticket", "book" attends to "plane" and "ticket", which shows it's a verb.
  • Key strength: capturing long-range relationships.
  • Maps inputs (x₁…xₙ) to outputs (y₁…yₙ). For y₃: score x₃ against x₁, x₂, x₃ with dot products → softmax → weighted sum.
Simple version (no weights)
scoreᵢ = x₃·xᵢ αᵢ = e^scoreᵢ / Σⱼ e^scoreⱼ y₃ = α₁x₁ + α₂x₂ + α₃x₃
With query, key and value
Q = X·W_Q K = X·W_K V = X·W_V
Attention(Q, K, V) = softmax( QKᵀ / √d_k ) V

Query = the current token asking. Key = what each token is compared against. Value = what gets mixed into the output. √d_k (key dimension) keeps the dot products from getting too large.

Watch for
  • Scores use the query of the current token and the keys of all tokens (including itself). The output mixes the values.
  • The slides skip √d_k (treat it as 1). If a question gives d_k, divide the scores by √d_k before softmax.
  • Say whether you rounded the softmax. The slides round to 1 decimal place and drop very small weights to 0 (0.063 → 0), which is why their y₁ = [2.0, 7.0, 1.5] differs from the exact [1.94, 6.68, 1.60].

Multiple choice · 22

1. Which tokenisation method do modern Transformers mainly use?

  1. Word
  2. Character
  3. Subword (e.g. BPE)
  4. Sentence

Subword tokenisation handles unseen words while keeping the vocabulary small.

2. "studies" → "studi" is an example of:

  1. Lemmatisation
  2. Stemming
  3. Tokenisation
  4. Chunking

"studi" isn't a real word, so it's stemming. Lemmatisation would give "study".

3. In BPE, which pair is merged at each step?

  1. The rarest pair
  2. The first two characters of each word
  3. A random pair
  4. The most frequent adjacent pair

BPE repeatedly merges the most frequent adjacent pair of symbols.

4. In an HMM POS tagger, P(word | tag) is called the:

  1. Emission probability
  2. Transition probability
  3. Prior probability
  4. Posterior probability

Emission = probability that a tag produces a word. Transition = tag followed by tag.

5. Which phrase matches NP: {<DT>?<JJ>*<NN>}?

  1. runs/VB quickly/RB
  2. the/DT very/RB
  3. big/JJ red/JJ ball/NN
  4. the/DT the/DT dog/NN

DT is optional and JJ can repeat, so JJ JJ NN matches. Two DTs don't match (? allows at most one).

6. "Apple Inc." would be labelled by NER as a:

  1. Person
  2. Organisation
  3. Location
  4. Date

Companies, universities and the UN are organisations.

7. Which is NOT a problem with one-hot encoding?

  1. Sparse vectors
  2. No notion of similarity between words
  3. Cannot represent out-of-vocabulary words
  4. Vectors are too short to store a large vocabulary

One-hot vectors are as long as the vocabulary, so they're too long, not too short.

8. In a term-document matrix, a column represents:

  1. A document vector
  2. A word vector
  3. A context window
  4. A vocabulary

Rows are words, columns are documents.

9. Why is cosine similarity preferred over the raw dot product?

  1. It is faster
  2. It can be negative
  3. It normalises for vector length, so frequent words aren't favoured
  4. It ignores zeros

The dot product grows with vector length. Cosine divides by both lengths.

10. A word that appears in every document has IDF equal to:

  1. 1
  2. 0
  3. N
  4. log₁₀(N)

IDF = log₁₀(N/N) = log₁₀(1) = 0.

11. PPMI is normally computed on:

  1. A term-document matrix
  2. A one-hot matrix
  3. A bag-of-words vector
  4. A term-term (word-context) matrix

TF-IDF pairs with TDM; PPMI pairs with TTM.

12. In skip-gram with negative sampling, a negative sample is:

  1. The target word paired with a random word from the vocabulary
  2. A word with a negative sentiment
  3. A word removed as a stop word
  4. A pair with a negative dot product

Negative samples are fake (target, random word) pairs.

13. The "naive" assumption in Naive Bayes is that:

  1. All classes are equally likely
  2. Word order matters
  3. Each word is independent of the others (given the class)
  4. The vocabulary is fixed

That's what lets us multiply P(wᵢ | c) for each word.

14. Why use add-1 (Laplace) smoothing in Naive Bayes?

  1. To speed up training
  2. To avoid zero probabilities for words unseen in a class
  3. To remove stop words
  4. To normalise document length

One zero likelihood would make the whole product zero.

15. Logistic regression outputs a probability by applying which function to w·x + b?

  1. ReLU
  2. Softmax over words
  3. tanh
  4. Sigmoid

σ(z) = 1/(1 + e^−z) maps any z to a probability between 0 and 1.

16. What does dropout do in a CNN?

  1. Randomly disables neurons during training to reduce overfitting
  2. Removes stop words
  3. Shrinks the feature map
  4. Sets negative values to zero

Pooling shrinks maps; ReLU zeroes negatives; dropout fights overfitting.

17. Which model is decoder-only?

  1. BERT
  2. T5
  3. GPT
  4. RoBERTa

BERT and RoBERTa are encoders; T5 and BART are encoder–decoder.

18. In self-attention, the output for a token is a weighted sum of the:

  1. Queries
  2. Values
  3. Keys
  4. Attention scores

Scores come from Q·K; softmax weights then mix the V vectors.

19. In the logistic regression slides, a review is classified positive when:

  1. z > 0.5
  2. w·x > b
  3. σ(z) > 0.5
  4. σ(z) > 1

The decision threshold is on the probability σ(z). Note that σ(z) > 0.5 is the same as z > 0, not z > 0.5.

20. "brown fox" is an example of a:

  1. Unigram
  2. Bigram
  3. Lemma
  4. Named entity

Two consecutive words = bigram (2-gram).

21. Precision is:

  1. (TP + TN) / total
  2. TP / (TP + FN)
  3. TN / (TN + FP)
  4. TP / (TP + FP)

Precision = of everything predicted positive, the share that really is positive. TP / (TP + FN) is recall.

22. Two events are mutually exclusive when:

  1. They cannot happen at the same time
  2. One does not affect the other
  3. They have equal probability
  4. Their probabilities sum to 1

Mutually exclusive: P(A and B) = 0. Independent means P(A and B) = P(A)P(B).

Written · 12

1. Compare stemming and lemmatisation, with one example each.
Stemming chops word endings with rules; the result may not be a real word (flies → fli). Lemmatisation uses a dictionary to return the base form, which is always a real word (flies → fly). Lemmatisation is more accurate; stemming is faster.
2. Using the "Will can spot Mary" corpus, compute the probability of tagging "Mary will see Jane" as N M V N.
<S>→N 3/4 × Mary|N 4/9 × N→M 3/9 × will|M 3/4 × M→V 3/4 × see|V 2/4 × V→N 1 × Jane|N 2/9 × N→<E> 4/9 = 0.00309.
3. Compute the cosine similarity of [1, 2, 0] and [2, 1, 2].
Dot = 2 + 2 + 0 = 4. |a| = √5 = 2.236, |b| = √9 = 3. cos = 4 / 6.708 = 0.596.
4. A word appears 9 times in a document and in 10 of 1000 documents. Compute its TF-IDF.
TF = log₁₀(10) = 1. IDF = log₁₀(1000/10) = 2. TF-IDF = 2.
5. Given P(w,c) = 0.1, P(w) = 0.2, P(c) = 0.25, compute PPMI. What if P(w,c) = 0.02?
0.1 / 0.05 = 2 → log₂ 2 = 1. With 0.02: 0.02/0.05 = 0.4 → log₂ 0.4 = −1.32 → PPMI = 0.
6. Naive Bayes with the slides' movie-review data: classify "disappointed movie".
Positive: P(disappointed|+) = 1/29, P(movie|+) = 2/29 → 3/5 × 1/29 × 2/29 = 1.43 × 10⁻³. Negative: P(disappointed|−) = 2/30, P(movie|−) = 2/30 → 2/5 × 2/30 × 2/30 = 1.78 × 10⁻³. Predict negative.
7. Using the slides' logistic regression weights, classify "disappointed movie". Does it agree with Naive Bayes?
z = −0.331 + 0.037 + 0.325 = 0.031 → σ = 0.508 > 0.5 → positive. It disagrees with Naive Bayes (negative). The bias pushes towards positive, and "movie" has a slightly positive weight. Both models are trained on only five reviews, so they're unreliable on borderline text.
8. Logistic regression: x = [1, 2], w = [0.5, −0.25], b = 0.5. Find z, σ(z) and the class.
z = 0.5 − 0.5 + 0.5 = 0.5 → σ = 1/(1 + e^−0.5) = 0.622 > 0.5 → class 1.
9. A spam filter gives TP = 30, FP = 10, FN = 20, TN = 140. Compute accuracy, precision, recall and F1.
Accuracy = 170/200 = 0.85. Precision = 30/40 = 0.75. Recall = 30/50 = 0.60. F1 = 2(0.75)(0.60)/1.35 = 0.667.
10. Simple self-attention with x₁ = [1, 0], x₂ = [0, 1], x₃ = [1, 1]. Compute y₃ (no weight matrices).
Scores: x₃·x₁ = 1, x₃·x₂ = 1, x₃·x₃ = 2. e¹ = 2.718, e¹ = 2.718, e² = 7.389, sum = 12.825 → α = [0.212, 0.212, 0.576]. y₃ = 0.212[1,0] + 0.212[0,1] + 0.576[1,1] = [0.788, 0.788].
11. Apply 2×2 max and average pooling with stride 2 to [[2,4,1,0],[6,8,3,1],[0,1,5,7],[2,3,9,4]].
Max: [[8, 3], [3, 9]]. Average: [[20/4, 5/4], [6/4, 25/4]] = [[5, 1.25], [1.5, 6.25]].
12. Compare encoder-only, decoder-only and encoder–decoder Transformers, with one example model and task each.
Encoder-only (BERT): builds representations for classification or NER. Decoder-only (GPT): generates text one token at a time. Encoder–decoder (T5, BART): sequence-to-sequence tasks such as translation and summarisation.
